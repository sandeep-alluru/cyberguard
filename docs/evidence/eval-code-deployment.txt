## TWO PROBLEMS THIS STEP CAUGHT, both by RUNNING rather than reading
1. MISSING DEPENDENCY. The first deployment left tools/ga_evaluator_v3.py failing on the host with
   ModuleNotFoundError: refusal_rule_v3 - the evaluator's own dependency had never been staged. The
   local self-test passed because it was invoked from inside tools/; the deployed invocation from the
   repo root exposed it. Both refusal_rule_v3.py and safety_classifier_v3.py are now staged.
2. PARTIAL AUTHORITY. v2/candidates/nvd-authority-gC.json is still being built (75/288). Staging a
   partial cache would silently shrink the checked-CVE set, shrink the verified-id denominator, and
   drop G-C below its >=300 support floor - reporting a support shortfall caused by the deployment
   rather than by the model. The script now REFUSES to stage an incomplete authority and says so;
   it must be re-run after build_nvd_authority.py finishes, before scoring.
