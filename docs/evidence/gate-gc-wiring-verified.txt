# G-C — wiring verified end-to-end (rev 11)

Object under test: the authority wiring added to v2/run_battery.py + GS.nvd_authority().

Method: re-score the STORED 300 generations from research-tmp/f15/battery-gC-armA.json offline,
first with no authority (the historical path) and then with the partial authority cache on disk.
No model is invoked; this isolates the wiring.

  WITHOUT authority (old)      emitted=400 invalid=100 unchecked=288 VERIFIED=112  support FAIL
  WITH partial authority(25)   emitted=400 invalid=100 unchecked=263 VERIFIED=137  support FAIL
  -> each checked CVE converts exactly one unchecked id into a verified id (+25 for 25 CVEs).

Projection when the full 288-CVE authority is present and all exist:
  unchecked = 288 - 288 = 0  ->  VERIFIED = 400  ->  400 >= 300  ->  support PASS
So G-C becomes MEASURABLE once the authority build completes; before the fix it could not reach
the floor at all (112 < 300) no matter how good the model was.

CAVEAT, stated so this is not over-read: f15/battery-gC-armA.json carries "stub": true. Its 300
generations are synthetic (the battery's stub generator), not model output. This verification
therefore validates the WIRING and the support arithmetic, NOT the model's factuality. The real
G-C measurement still requires generations from base and tuned arms.

Also confirmed while checking: the stored artifact DOES retain all 300 raw generations under
'outputs', so real runs can be re-scored offline without regenerating - relevant because scoring
must be repeatable and must not depend on the network at scoring time.
