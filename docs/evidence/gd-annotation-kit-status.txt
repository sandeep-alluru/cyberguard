# G-D annotation kit — status and self-test (CyberGuard v3, 2026-09-30)

Context: §8.9 declares G-D STATUS: BLOCKED. Verified on the data:
  v2/candidates/arcspan-train-sample.jsonl -> 500 rows, 500 with empty-string labels, 0 non-empty.
  The scorer exists (cap_scorers.extract_iocs + ioc_score(gen, gold, source_text)); the gold
  reference does not. v2/gates_v2.py CONSUMES per-document span-F1 (bootstrap_lower_span_f1) but
  does not compute it, so the missing piece is genuinely the human reference bundle.

Delivered: tools/gd_annotation_kit.py --make/--verify implements the rest of the §8.9 protocol.
  v3/evals/gd/G-D-ANNOTATION-WORKSHEET.md   100 pinned docs (first 100 rows, deterministic)
  v3/evals/gd/bundle-A.jsonl                all 100 docs, schema-conformant template
  v3/evals/gd/bundle-B.jsonl                blind re-annotation of 20 docs, seed 20260930
  v3/evals/gd/kit-meta.json                 pinned row_idx list + recheck subset + span types

Verifier behaviour (tested):
  - unfilled templates -> FAIL with per-row 'no annotator name' problems; correctly reports
    mean span-F1 as None rather than a misleading 1.0
  - F1 unit checks: identical=1.0, disjoint=0.0, half=0.6667, type-mismatch=0.0 -> PASS
  - both-empty document pairs are EXCLUDED from the mean as uninformative, and the verifier
    requires >=80% of recheck docs to carry spans in either pass -- so empty-vs-empty can never
    be mistaken for agreement
  - annotator names are checked against a model-name list with WORD BOUNDARIES, so a human named
    'Kai' is accepted while 'gpt-6-astra' / 'GPT-4o' / 'an LLM' / 'claude-3' are rejected
    (the earlier substring version would have falsely rejected 'Kai')

Remaining work is human: one annotator fills 100 documents with character-offset spans, a
different annotator blindly re-annotates 20, then --verify computes the agreement and writes
v3/evals/gd/G-D-ANNOTATION-RECEIPT.json with both bundle SHA-256s.

Not done, deliberately: no span is model-drafted, and the verifier rejects model-named annotators.
