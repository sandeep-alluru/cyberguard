# G-B's ranking ROC-AUC is now implemented (rev 11, round 22)

Objective item (2) directs that "G-B must supply the specified ranking ROC-AUC, not hard-label
(TPR+TNR)/2". This is what was done — and it did NOT require a new instrument.

## THE INSIGHT

I had earlier reported G-B as an "unmeasurable spec" because the probes demand "One word only" and no
stored output carries a score field. That is true of the STORED outputs, but it is not a property of the
instrument: `model.generate` can return the model's own distribution at the first generated token. Under
the IDENTICAL greedy decode, P(malicious) vs P(benign) at that token is a genuine per-item ranking score,
and the argmax still yields exactly the same hard label as before. So G-B gains its required ROC-AUC from
the same 300 probes, with nothing already measured invalidated.

## IMPLEMENTED

1. `eval_cyberguard.triage_score_from_logits(logits, tok)` — softmax over ONLY the two candidate tokens
   (so the score is a comparison between the answers the task asks for, not a function of unrelated
   vocabulary mass). Returns None when a candidate token is unresolvable — a real shortfall, never an
   invented 0.5.
2. `eval_cyberguard.generate_batch_scored(model, tok, batch)` — identical decode surface to
   `generate_batch` (greedy, same padding, same max_new) plus `output_scores=True`; returns (texts,
   scores). The text is byte-identical to the existing path.
3. `v2/run_battery.py` — only the gB battery uses the scored variant (every other battery keeps the plain
   shared surface untouched) and reports `scores["ranked"]` + `scores["triage_scores"]`. Absent scores
   stay absent; nothing is substituted.
4. `v2/gate_scorers_v2.py` — `auc_ranked` (Mann-Whitney with average ranks for ties) and
   `score_triage_ranked` (real ROC-AUC + supporting counts).
5. `v2/gates_v2.py` — the G-B gate now requires the REAL ranked AUC: `holds = precision >= 0.90 AND
   fpr <= 0.05 AND auc_ranked >= 0.95`. The hard-label `(tpr+tnr)/2` is retained as a REPORTED
   diagnostic only, labelled as "a single operating point, not a curve". Without scores the gate is
   UNMEASURED for the ranking half, never satisfied by the surrogate.
6. `v2/assemble_gate_inputs.py` — passes `triage_ranked` through when (and only when) real scores exist.

## VERIFIED

ROC-AUC against hand-computed cases (7/7):
    perfect separation 1.0 | perfect inversion 0.0 | all tied 0.5 | one-vs-one 1.0
    [1,2,3,4] with golds [mal, ben, mal, ben] -> 0.25   (hand-checked: pairs (1,2)0 (1,4)0 (3,2)1 (3,4)0 = 1/4)
    [1,2,3,4] with golds [ben, mal, ben, mal] -> 0.75
    separation with an interior tie -> 0.875
  Degenerate inputs return None (single class) or an explicit error (non-numeric score / bad gold) --
  never a fabricated value.
  NOTE: one of my own expected values was wrong on the first run (I wrote 0.75 for the 0.25 case); the
  hand-computation above confirmed the IMPLEMENTATION was right and the expectation was wrong.
Score conversion (torch, locally): strong malicious 0.9997 | strong benign 0.0003 | exact tie 0.5000 |
unresolvable token -> None.

`v2/gates_v2.py --selftest`: PASS, including the updated F17 case ("consistent identity, but NO scores ->
ranking UNMEASURED") and a NEW positive case ("consistent identity AND a real ranked AUC=0.97 -> G-B
PASS") so the suite cannot be satisfied by always returning UNMEASURED.

## A DEPLOYMENT GAP CAUGHT WHILE DOING THIS
`eval_cyberguard.py` was NOT in the staging list, so the first deployment would have left the host
decoding WITHOUT score capture — G-B would have silently reported the ranking requirement UNMEASURED for
a deployment reason. Added to `tools/stage-eval-code-v3.sh` (the same class of miss as the earlier
`refusal_rule_v3` dependency, caught the same way: by running the deployed code rather than reading it).

## WHAT REMAINS
The actual AUC VALUE can only be produced with the GPU, which is busy training. Post-training the gB
battery will emit real scores for both arms and the gate will apply the >=0.95 bar. Owner decision D3 is
therefore REDUCED, not open in its original form: the plan's ranking requirement is now implementable as
written, so the choice is no longer "relax the gate or build a new instrument".
